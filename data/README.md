# 数据集目录

本目录用于存放图像分割数据集。

## 目录结构

```
data/
├── images/      # 原始图像
│   ├── sample_001.png
│   ├── sample_002.png
│   └── ...
└── labels/      # 分割标签(与图像同名)
    ├── sample_001.png
    ├── sample_002.png
    └── ...
```

## 数据格式要求

### 图像
- 格式：PNG / JPG / BMP / TIFF
- 通道：RGB（3通道）或灰度图
- 尺寸：建议统一尺寸（如 256x256、512x512）

### 标签
- 格式：PNG / TIFF（推荐无损格式）
- 通道：单通道
- 标签值：
  - 二分类：背景=0，前景=1
  - 多分类：0, 1, 2, ..., num_classes-1

## 命名规则

图像与标签文件名必须一一对应（不含扩展名），例如：
- 图像：`sample_001.png`
- 标签：`sample_001.png`

## 自动校验

数据集校验器（`pipeline/dataset_validator.py`）会在 Agent 启动时自动检查：
1. 图像与标签数量是否匹配
2. 文件格式是否支持
3. 图像与标签尺寸是否一致
4. 标签值是否在合法范围内
5. 文件是否可正常读取

## 合成数据

如果暂无真实数据集，可使用合成数据运行完整流程：
```bash
python main.py --synthetic --num_samples 20 --img_size 64
```
